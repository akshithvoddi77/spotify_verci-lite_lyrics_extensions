# Verci Lite

A lightweight [Spicetify](https://spicetify.app/) extension for Spotify that displays synced lyrics word-by-word over an animated space scene.

## Features
* **7 Visual Lyric Styles:** `warp` (default), `stack`, `fisheye`, `code`, `constellation`, `branches`, and `web`.
* **3 Backgrounds:** `space` (animated starfield with shooting stars), `black`, and `clear` (blurred dark glass).
* **Flexible Display:** Switch between a draggable floating panel (small, medium, or large) and fullscreen mode.
* **Live Lyric Fetching:** Fetches synced lyrics live from Spotify (with LRCLIB as a fallback) without storing anything locally.

## Prerequisites
* Desktop Spotify installed
* [Spicetify](https://spicetify.app/docs/getting-started) installed and configured
